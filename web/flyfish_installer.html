Waterfall Flying Fish

Chopin's Étude Op. 10 No. 1 on the M-VAVE FM-1, on Felucca

Connect the FM-1 directly to the computer with a USB data cable and press Install. Chrome or Edge on a computer; allow MIDI when the browser asks.

Do not unplug the cable or close this page while it writes.

Flyfish was built for love of one piece: it comes with no warranty. If the FM-1 misbehaves, install Felucca again, or return to the official firmware below. Flyfish keeps its settings and practice chart in Felucca's first two song slots: back up anything you made in Felucca first (Felucca's editor). If an install is cut off, press Install again: the FM-1 stays in update mode until it is finished. An FM-1 that no longer starts at all needs a Transporter.

Install a test build

A Flyfish package from a test build (GitHub: Actions > the run > Artifacts > flyfish-firmware, its .fwsc). It is checked here, in the browser, and not sent anywhere. Install above puts the released Flyfish back.

Return to the official firmware (V15)

Get the official FM-1 V15 from M-VAVE and select its unmodified FM-1.fwsc. It is checked here, in the browser, and not sent anywhere. Flyfish's settings and practice chart are not kept.
